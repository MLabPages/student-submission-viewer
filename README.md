# 提出物連続確認ツール

学生の Word、PowerPoint、PDF、画像を連続確認するWindowsデスクトップアプリです。提出物は外部へ送信せず、利用者のPC内で処理します。

## すぐ使う

[最新版のダウンロードページ](https://github.com/MLabPages/student-submission-viewer/releases/latest)から `Setup.1.2.0.exe` をダウンロードして実行します。インストール後は、スタートメニューまたはデスクトップの「提出物連続確認ツール」から起動できます。

初回にWindowsの保護画面が表示された場合は、発行元とダウンロード元がこのリポジトリであることを確認してから「詳細情報」→「実行」を選択してください。

## 作品を探す・内容を確認する

- 「作品を探す」を押すと、画面全体に大判サムネイルが並びます。
- サムネイルを選ぶと通常画面へ戻り、提出物の内容を確認できます。
- 提出物一覧とプレビューの間にある境界線を左右へドラッグすると、表示領域の幅を調整できます。
- 境界線をダブルクリックすると標準の幅へ戻ります。調整した幅は次回起動時も維持されます。

## 開発者向け

開発中にデスクトップ版を起動する場合は、最初に `npm install`、以後は `npm run desktop` を実行します。インストーラーは `npm run dist` で `dist` フォルダに作成されます。

### 従来のローカルWeb版を起動する

`start-viewer.cmd` をダブルクリックします。ブラウザーに画面が開いたら「フォルダを選択」を押し、表示された画面で提出物のフォルダを選んでください。選択後は自動で読み込みます。選択画面が見えない場合は、ブラウザー画面の後ろに出ていないか確認してください。

### ローカルWeb版のショートカットを作る

毎回ツールのフォルダを開かなくても、デスクトップの専用アイコンから起動できます。

1. 初回だけ `create-desktop-shortcut.cmd` をダブルクリックします。
2. 「Desktop shortcut created successfully.」と表示されたら作成完了です。
3. 以後は、デスクトップの「提出物連続確認ツール」をダブルクリックします。

専用ショートカットから起動すると、黒いコマンド画面をほとんど表示せずブラウザーが開きます。ツールがすでに動いている場合は、二重起動せずブラウザー画面だけを開きます。

ショートカットはこのツールの保存場所を参照します。作成後にフォルダを移動した場合は、古いショートカットを削除して `create-desktop-shortcut.cmd` をもう一度実行してください。

手動で作成する場合は、`start-viewer.cmd` を右クリックし、「その他のオプションを確認」→「送る」→「デスクトップ（ショートカットを作成）」を選びます。

## 主な機能

- 現在の提出物を最優先でPDF化
- 次の3ファイルをバックグラウンドで先読み
- 変換済みPDFを再利用し、元ファイル更新時だけ再変換
- サブフォルダを含む提出物一覧と検索
- スクロール可能なリスト表示とPDF先頭ページのサムネイル表示
- 一覧とプレビューの境界をドラッグして幅を調整（表示ごとに幅を記憶）
- 「作品を探す」で画面全体に大判サムネイルを表示
- フォルダ読込直後からの全提出物の自動PDF準備と進捗表示
- 前後のファイルへの連続移動
- 状態、点数、メモの自動保存
- 評価結果のCSV出力
- 元ファイルをWordまたはPowerPointで開く

## 対応形式

- Word: `.doc`, `.docx`
- PowerPoint: `.ppt`, `.pptx`
- PDF: `.pdf`
- 画像: `.jpg`, `.jpeg`, `.jfif`, `.png`, `.gif`, `.webp`, `.bmp`
- その他の画像: `.avif`, `.apng`, `.ico`
- Word・文書: `.docm`, `.rtf`, `.odt`, `.txt`
- PowerPoint・スライド: `.pptm`, `.pps`, `.ppsx`, `.odp`
- Excel・表計算: `.xls`, `.xlsx`, `.xlsm`, `.xlsb`, `.csv`, `.ods`

未対応形式も一覧から除外しません。件数を画面上部に出し、各ファイルへ紫色の「未対応」ラベルを表示して、元ファイルを開いて確認できます。Apple Pages（`.pages`）／Keynote（`.key`）／Numbers（`.numbers`）、iPhone写真のHEIC／HEIF、ZIP、TIFFなどが含まれていても、提出物の存在を見落とさない設計です。

WordとPowerPointの変換には、このPCにインストールされているMicrosoft Officeを使います。提出物は外部へ送信されません。元ファイルは変更しません。

一時PDFと評価データは `%LOCALAPPDATA%\StudentSubmissionViewer` に保存されます。

## セキュリティ

- サーバーは `127.0.0.1` のみに接続し、同じPC以外からはアクセスできません。
- 外部Webページからの操作を拒否するHost・Origin検証とセキュリティヘッダーを設定しています。
- Office変換時はマクロを無効化し、ファイルを読み取り専用で開きます。
- CSV出力はExcelの数式として解釈される文字列を無害化します。
- 「元ファイルを開く」は通常のOfficeアプリで開くため、Officeの保護ビューや警告を解除する前に提出元を確認してください。

脆弱性と思われる問題は、公開のIssueでは学生情報や実ファイルを添付せず、再現手順だけを報告してください。
